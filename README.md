# Portfolio scaffold

This folder now has a Next.js App Router portfolio structure ready for content and design work.

## Structure

- `app/` for routes, layout, and global styles
- `components/sections/` for page sections
- `components/ui/` for reusable UI pieces
- `data/` for portfolio content
- `lib/` for shared config and helpers
- `public/` for static assets
